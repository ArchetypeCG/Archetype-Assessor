# Individual off-the-job progress

Each apprentice’s panel totals their own Approved OTJ log entries for the current standard, dated on or before the selected target date. Pending and returned entries, other apprentices’ logs and entries from a previous standard do not contribute. The panel displays the apprentice’s name and reference to identify the calculation.

Expected hours use that apprentice’s total OTJ target, programme start and planned training end date, spread evenly across the training period. This is a planning comparison. Apprentices with the same dates and targets can correctly have the same expected hours; approved totals depend on their individual logs. Update programme dates and the total OTJ target to match each agreed training plan.

Portfolio, Off-the-job log, learning plans and scheduled-session views use the same calculation. Selecting another apprentice resets the comparison date to its default. Dashboard totals use approved hours up to today. Existing records are preserved.
